<h1> HTML Tags </h1>

A hands-on list of HTML tags. Each one comes with a plain explanation, a live example drawn by your browser, and the code behind it.

Tag What it does Example
Page structure
<html> The root of the page. Every other tag goes inside it. The lang attribute tells browsers and screen readers which language the page is in. 
<!DOCTYPE html>
<html lang="en">
  <head>…</head>
  <body>…</body>
</html>
<head> Holds information about the page that is not shown on it: the title, meta tags, styles and links to other files. 
<head>
  <meta charset="utf-8">
  <title>HTML Tags</title>
</head>
<body> Holds everything you see on the page: text, images, tables, forms and more.

Everything on this page, including this table, is inside the body.

<body>
  <h1>Hello!</h1>
  <p>This is my first web page.</p>
</body>
<main> Wraps the main content of the page, the part that is unique to it. Use only one main per page.

On this page, the tag table sits inside main.

<main>
  <h1>HTML Tags</h1>
  <p>The list of tags goes here.</p>
</main>
Metadata
<title> Sets the name shown on the browser tab, in bookmarks and in search results.

Look at your browser tab: it says “HTML Tags”.

<title>HTML Tags</title>
<base> Sets the starting address for every relative link on the page. Only one base is allowed, inside head.

With this base, a link to about.html opens https://example.com/docs/about.html. This page doesn't use base, so the example is code only.

<base href="https://example.com/docs/">
<link> Connects the page to an outside file, most often a stylesheet or a font. For clickable links, use the a tag.

This page uses link to load its fonts from Google Fonts.

<link rel="stylesheet" href="style.css">
<meta> Gives browsers and search engines extra facts about the page, such as its character set, its description, and how it should scale on phones. 
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="description" content="A list of HTML tags">
<style> Holds CSS rules that style the page. It usually goes inside head. 
<style>
  .red-text { color: crimson; }
</style>

This sentence is red.

Grouping content
<p> A paragraph of text. Browsers add space above and below it.

This is the first paragraph.

This is the second one. Notice the gap between them.
<pre> Preformatted text. Spaces and line breaks are kept exactly as typed, in a monospace font.

     under   the   sun
<blockquote> A longer quotation from someone else, shown indented by default.

<ol> A numbered list. Use it when the order matters, like steps in a recipe.
  1. Boil the water
  2. Add the tea leaves
  3. Pour and enjoy
<ul> A bulleted list, for items where the order doesn't matter.
  • HTML
  • CSS
  • JavaScript
<li> One item in a list. It goes inside an ol or a ul.
  • Car
  • Cycle
  • Mobile
  • Laptop
<dl> A description list: pairs of terms and their descriptions, like a glossary.

<dt> The term in a description list. It goes inside a dl.

The capital of Bangladesh.
<dd> The description of the term above it. Browsers indent it.

<figure> A self-contained item like a photo, a chart or a code sample, usually with a caption.
<figcaption> The caption of a figure. It goes first or last inside the figure.
<div> A plain box with no meaning of its own. It groups things together so you can style or arrange them.
I am a div. The dashed border comes from its style attribute.
<hr> A thematic break: a line that separates one topic from the next.

<a> A link to another page, a file, an email address or a spot on the same page.

<em> Stress emphasis, the way you would say a word louder. Shown in italics by default.

<strong> Text of strong importance, like a warning. Shown in bold by default.

<cite> The title of a creative work, such as a book, a film or a song. Shown in italics.

Clean Code is a book by Robert C. Martin.
<q> A short quotation inside a sentence. The browser adds the quote marks for you.

<span> A plain inline container with no meaning of its own, often used to style a few words.

My favourite colour is blue.

<mark> Highlighted text, like a marker pen on paper.

Search results for HTML are highlighted.
<code> A short piece of computer code inside text, shown in a monospace font.

<kbd> Keyboard input, like a key or a shortcut.

Edits
<ins> Text that was added to a document. Underlined by default.

I like blue.
<del> Text that was removed from a document. Shown with a line through it.

I like red blue.
Images and media
<img> Adds an image. The alt text describes it for people who can't see it, and shows if the image fails to load.
<area> A clickable region inside an image map. It goes inside a map, which is linked to an img with the usemap attribute.

Click the street light to open the full photo, or the person to jump to the figure tag.
<video> Plays a video. The controls attribute adds play, pause and volume buttons.
<audio> Plays a sound file, like a song or a podcast.
<iframe> Shows another web page inside this one, like a map or a video player.
<svg> Draws vector graphics: shapes and text that stay sharp at any size.

Forms
<form> Collects input from the visitor and sends it somewhere. This demo doesn't send anything.





<label> Names a form control. Clicking the label also clicks its control, which is easier on phones.
<input> A form field. The type attribute turns it into a text box, a slider, a colour picker, a date picker and more.

<button> A clickable button. Inside a form it sends the form, unless you set type="button".
<select> A drop-down list. Each choice is an option tag inside it.
<textarea> A text box for several lines of text, like a message or a comment.

Interactive
<details> A box that opens and closes when you click it. No JavaScript needed.

<summary> The always-visible label of a details box. Clicking it opens or closes the box.

<dialog> A pop-up box that appears on top of the page. A form with method="dialog" closes it.

Hello! I am a dialog box.
Scripting
<script> Adds JavaScript to the page. Here it waits for a click, then writes a message.

<canvas> A blank drawing area. JavaScript draws shapes, charts or games on it.
